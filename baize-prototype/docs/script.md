## 1. 开场旁白（标题页 → 选人页之间，约 20 秒，可跳过）

1. 天地有灵，五行分野。木生于东，火炎于南，水寒于北，土厚于西。
2. 四域交汇之处，沉睡着上古神兽——**白泽**。它通晓万物，辟邪驱魔。
3. 传说：凡人若能在秘境中修至化神，便可得白泽点化，渡劫飞升。
4. 今日，秘境之门大开。四名出身凡尘的散修，踏上了问道之路……
5. （画面定格在棋盘全景）**白泽秘境，开启。**

## 3. 新手引导（首局自动开启，6 步，每步一个高亮框和一句提示）

1. **掷骰**：「按空格掷骰。两颗骰子的点数之和，就是你要走的格数。」
2. **买地**：「这块灵田无主。买下它，别人路过就要向你交租。」
3. **岔路**：「前面是山门。拐进问道之路能抄近道，还能去白泽灵台。」
4. **修为**：「修为是胜负的关键。先修到 10 点的人渡劫飞升，赢下这局。」
5. **突破**：「你已到筑基，可以去白泽灵台突破，换一门永久神通。」
6. **符箓**：「手里的符箓要花灵丹才能施放。灵丹还能用来突破和发动大招，省着点用。」

## 7. 胜利与结算

- **渡劫飞升**：天空裂开金光，白泽仰天长啸，胜者棋子化作光点升空。字幕：「{name} 渡劫飞升」
- **回合上限胜利**：字幕：「秘境闭合 · {name} 得道」
- 结算页逐行展示：修为来源分布（筑府 / 灵脉 / 历练 / 斩妖 / 悬赏 / 白泽）、总资产、突破次数、所获神通。
