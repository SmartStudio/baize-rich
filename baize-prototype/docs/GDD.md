| 类型 | 像素风 · 东方修仙 · 大富翁式桌游 |
| 平台 | PC / 网页横屏 16:9，鼠标 + 键盘 |

### 一句话概念
凡人出身的散修踏入白泽秘境，掷骰巡游四大灵域，圈灵田、建洞府、斗法夺机缘，求得白泽点化，率先修至化神、渡劫飞升。

### 设计支柱
1. **熟悉易上手**：掷骰 → 买地 → 收租的大富翁骨架不变。
2. **修仙成长感**：修为推进境界，境界在白泽灵台突破换取永久神通。
3. **每回合都有选择**：岔路选线、地形规则、符箓、突破时机，运气约 40%、策略约 60%。
4. **修士之间有交锋**：路上遇到就能斗法，领先者头顶悬赏令，洞府可布禁制，每名修士都有一个针对他人的主动技能（§12、§17）。

### 题材与 IP 说明
风格借鉴「凡人修仙」类题材的通用元素（灵根、境界、灵石、丹药、符箓、洞府、坊市、天劫心魔等）。**不使用任何具体小说中的人物名、地名、宗门名、法宝名**；如需与特定作品做 IP 联动，需另行取得授权。

## 1. 世界观

上古神兽**白泽**通晓万物、辟邪驱魔，沉睡于秘境中心的**白泽灵台**。秘境被五行之力划分：

| 五行 | 灵域 | 位置 | 主色 | 地形规则 |
|---|---|---|---|---|
| 木 | 青木灵林 | 下边 | 青绿 | 迷踪 |
| 火 | 赤焰火域 | 左边 | 赤橙 | 地火喷发 |
| 水 | 玄冰寒渊 | 上边 | 冰蓝 | 寒冰滑行 |
| 土 | 厚土瘴泽 | 右边 | 紫褐 | 瘴泽泥沼 |
| 金 | 白泽灵台 | 中央 | 白 / 金 | 突破与点化 |

> 五行中「金」对应白色，白泽居中、属金，四方灵域环绕。

玩家是四名出身凡人的散修，各修一道（体修、法修、剑修、丹师）。**域外天魔**会周期性侵入秘境，白泽则会在中盘现世一次。

### 3.3 移动规则
1. 掷 2 颗 D6，按点数逐格前进；每进入一个节点算 1 步。
2. **岔路**：当前位置是山门且还有剩余步数时，选择「继续外环」或「拐入神道」。回合开始时就站在山门上也可以选择。
3. **神道**：只能向内走，S1 → S2 → ALTAR。
4. **白泽灵台**：走到灵台时，如果还有剩余步数，可以：
   - **停留**：移动立即结束，在灵台结算（见 §9）；
   - **借道**：支付 1 灵丹，选一条神道向外离开，继续移动（X2 → X1 → 山门 → 沿外环顺时针）。
   没有灵丹，或剩余步数为 0 时，必须停留。
5. **离开灵台**：下回合从灵台出发时，任选一条神道向外走。
6. 外环始终顺时针前进，「迷踪」与「回首符」例外。
7. 一次移动穿过两座山门时，满足机缘任务「一回合经过两座山门」。

### 3.4 灵域地形规则

| 灵域 | 规则 | 说明 |
|---|---|---|
| 木 · 迷踪 | 回合结束时停在木灵田上，下回合可选择逆时针移动 | 逆时针时同样可以在山门拐入神道 |
| 火 · 地火喷发 | 第 4、8、12 轮结束时，随机一座有主的火域草庐（Lv1）被毁、降为空地 | 金光符、神通「金身」、天赐「白泽护道」可抵挡 |
| 水 · 寒冰滑行 | 移动在水灵田上结束时，沿当前方向再滑 1 格，每次移动限 1 次 | 滑到山门时不触发岔路选择，按原方向继续 |
| 土 · 瘴泽泥沼 | 本回合第一次进入土灵田时，剩余步数 −1；本回合总步数至少 1 | 每回合只触发一次 |

## 5. 灵田与洞府

### 5.1 地价
P 为售价，R 为基础租金（R = 10% × P）。

| 灵域 | 5 块灵田售价 P（按外环顺序） |
|---|---|
| 木 · 青木灵林 | 100 / 110 / 120 / 130 / 140 |
| 火 · 赤焰火域 | 260 / 270 / 280 / 290 / 300 |
| 水 · 玄冰寒渊 | 200 / 210 / 220 / 230 / 240 |
| 土 · 厚土瘴泽 | 160 / 170 / 180 / 190 / 200 |

### 5.2 洞府等级

| 等级 | 名称 | 升级花费 | 租金 | 修为 |
|---|---|---|---|---|
| Lv0 | 空地 | 买入 P | 1R | — |
| Lv1 | 草庐 | +0.5P | 3R | — |
| Lv2 | 精舍 | +0.5P | 6R | 首次建成 +1 |
| Lv3 | 楼阁 | +1P | 10R | 首次建成 +1 |
| Lv4 | 仙府 | +1P + 2 灵丹 | 15R | 首次建成 +1 |

- **升级**：在行动阶段，可升级自己任意一块洞府 1 级，每回合最多 1 次。
- **灵脉之主**：在某一灵域拥有的灵田最多且至少 3 块，即为该灵域的灵脉之主，获得 +2 修为（动态计算，被反超即失去）。持平时由先达成者保持。
- **一域独占**：拥有某灵域全部 5 块灵田时，该灵域租金 ×2。
- **终局**：第 10–12 轮所有租金 ×1.5。
- 各项倍率相乘后向下取整。

## 6. 回合流程

每名玩家行动一次为 1 个回合轮次（round），共 12 轮。单个玩家的回合（turn）按以下顺序进行：

1. **回合开始**：结算持续效果（护道、定身、面壁等）；神通「丹心」生效；自己布下的山岳（镇山）消散。
2. **掷骰前窗口**：可施放身法符、财运符；剑修「剑遁」、法修「乾坤挪移」在此发动（§12）。
3. **掷骰**：2D6；神通、符箓可修改点数。
4. **移动**：岔路选择 → 地形效果 → 灵台借道 / 停留。移动结束后，可向落点或途中经过的一名修士**斗法**（§17）。
5. **落点结算**：买地 / 付租（可用护体符反制）/ 禁制（§17）/ 地块效果 / 灵台结算。
6. **行动阶段**：升级 1 次、施放符箓、发动大招、布禁制，体修「镇山」、丹师「迷魂丹」在此发动。交易首版不做。
7. **回合结束**：检查任务；修为 ≥ 8 立即渡劫飞升，游戏结束。掷出双数时再掷一次，最多连续 2 次；第 3 次双数送思过崖。

每轮开始前依次检查：天魔出现与离开（§10）、白泽现世（第 6 轮，§9.3）、悬赏令（§17）。地火喷发在第 3/6/9 轮结束时。

## 7. 胜负

- **主胜利（荣耀竞赛 · 渡劫飞升）**：修为先达到 8 点的玩家立即获胜。
- **回合上限**：第 12 轮结束时修为最高者获胜；平局比总资产（灵石 + 洞府造价总和 + 灵丹 × 50）。
- **无淘汰 · 破产重整**：需要支付而灵石不足时，付出全部灵石（差额免除），之后：所有灵田归还（建筑清空），领取 300 灵石，修为 −2（最低为 0）。
- 可选规则（自定义房间，首版可不做）：经典破产淘汰；8 轮快速局比总资产。

## 9. 白泽赐福 v3

### 9.1 设计目标
- 把中心地图和修仙核心「境界突破」绑在一起，给玩家进神道的理由。
- 赐福是永久成长（神通），而不是一次性交易。
- 中盘安排一次固定的高潮事件，并向落后者倾斜。

### 9.2 白泽灵台（常驻）
停留在灵台时，三选一：

1. **突破**：需要至少 1 次突破机会。消耗灵丹 = 本次是第几次突破（第 1 次 1 颗，第 2 次 2 颗……最多 3 颗）。持有祠印 −1，天魔在场 +1，最低 0。然后从**该玩家自己的**神通牌堆（8 种中排除已拥有的）翻 3 张（全场修为最低者翻 4 张），选 1 张永久生效，其余放回并洗牌。每次停留最多突破 1 次。
2. **静心**：+1 灵丹，并抽 1 张机缘卡。
3. **离开**：不结算。

借道穿过灵台时（§3.3）不能突破。

### 9.3 白泽现世（第 6 轮开始时，固定一次）
1. 若天魔在场，白泽将其驱散，无人获得斩妖修为。
2. 从天赐牌堆翻开与玩家人数相同的卡。按修为**从低到高**依次各选 1 张，平局时灵石少者先选。
3. 灵雨：本轮所有租金减半。

### 9.4 神通（突破所得，永久，每人最多 3 个，不可重复）

| ID | 名称 | 效果 |

## 10. 天魔（世界事件）

- 第 4 轮和第 8 轮开始时，在随机一块灵田（R1–R31 中的灵田）出现，生命值 6，最多停留 3 轮。第一只（第 4–6 轮）会在第 6 轮被白泽现世提前驱散。
- 每轮开始时，天魔沿外环顺时针移动 2 格。落在 Lv≥1 的洞府上时，该洞府降 1 级（镇妖、金身、护道可抵挡）。
- 天魔所在格的租金为 0。天魔在场时，突破费用 +1。
- **讨伐**：任何玩家都可以在自己的行动阶段用五雷符攻击天魔（2 伤害），法修大招造成 3 伤害；神通镇妖使伤害 ×2。造成最后一击者 +2 修为。

## 13. AI

难度：简单 / 普通 / 困难。性格：稳健 / 激进 / 守财（影响以下阈值）。

| 决策 | 普通难度的默认规则 |
|---|---|
| 买地 | 买后灵石 ≥ 300 就买；守财型阈值 600，激进型 150 |
| 升级 | 灵石 ≥ 升级费 + 400 时，升级租金收益最高的洞府 |
| 岔路 | 有突破机会且灵丹够付费用 → 进神道；前方 6 格内有高额租金（≥ 当前灵石 20%）→ 进神道；否则走外环 |
| 灵台 | 能突破就突破；否则灵丹 < 2 时静心，否则离开 |
| 借道 | 剩余步数 ≥ 3 且灵丹 ≥ 3 时借道 |
| 符箓 | 五雷符优先打修为第一名（可拿悬赏）；天魔生命 ≤ 伤害时优先讨伐 |
| 大招 | 收益估值 > 300 灵石等价时发动 |
| 选神通 / 天赐 | 按预设权重表；困难难度根据局势评分 |
| 斗法 | 估算胜率（2 颗骰点差 + 押注 + 英雄加成）× 赌注（含悬赏令修为）的期望，超过门槛就挑战；向修为领先者出手加分。门槛：简单 150、普通 30、困难 0 |
| 押注 | 双方赌注合计 ≥ 250 灵石押满，≥ 120 押 1 颗；守方看到攻方押注后按期望选择。简单难度不押 |
| 禁制 | 有空闲灵丹时，布在对手下一次掷骰最可能停下的自家洞府上 |
| 技能 | 按技能估值发动：剑遁看斗法期望 + 落点价值；乾坤挪移看换位后的期望落点；迷魂丹优先修为领先者；镇山看下一位对手经过的概率 × 该格租金 / 禁制 |

简单难度：买地 50% 随机，不主动使用攻伐符。困难难度：对岔路和买地做一步前瞻（对比 2–12 点的期望租金）。

## 16. 原型验证计划
纸面原型 3–5 局，每局记录：
- 单局时长；
- 进神道次数；
- 突破次数与时机；
- 第 10 轮的修为排名与最终名次是否一致（一致率越低，翻盘越多）；
- 每名玩家的「无事可做」回合数。

AI 自对弈（`npm run sim`）目标：
- 各英雄胜率 22–28%；
- 先手胜率优势 < 3%；
- 多数对局（≥ 70%）由修为 8 结束，平均 10–12 轮；
- 平均每人突破 1–2 次；
- 有玩家互动（付租、斗法、禁制、山岳、技能）的回合占比明显高于只靠付租的约 13%。

## 17. 斗法、悬赏令与禁制

本节的数值都在 `data/config.json` 的 `rules` 块（`duel*`、`bounty*`、`trap*`）。

### 17.1 斗法
- **时机**：一次掷骰移动（含双数再掷的每一次）走完后、落点结算前，可以向**落点上**或**途中经过的格子上**的一名他人发起斗法。每回合最多 1 次。传送、遁地、缩地、滑行不算相遇；剑修「剑遁」会直接发起斗法。
- **不能被挑战**：在思过崖面壁的人；本轮已经被挑战过一次的人（守方本轮受保护，攻方不受）。
- **押注**：攻方先押，守方看到后再押，各 0–2 颗灵丹，每颗 +1 点，无论胜负都消耗。
- **比点**：双方各掷 1 颗骰 + 押注 + 英雄加成（剑修攻方 +1，体修守方 +1）。点数高者胜，**平局守方胜**。
- **赌注**：败者把自己 20% 的灵石（向下取整，至多 300）交给胜者。这笔钱直接转交，不触发破产重整。
- **悬赏令**：若败者持有悬赏令，胜者另得 +1 修为，悬赏令揭下。

### 17.2 悬赏令
- 每轮开始时重新判定：修为**唯一最高**且至少 2 的玩家持令；并列或不足 2 时无人持令。持令者变化时全场公告。
- 持令者被斗法击败后，悬赏令撤下，直到下一轮开始重新判定。
- 与五雷符的「悬赏」（§8.1）是两条独立的路线。

### 17.3 禁制
- **布置**：行动阶段花 1 灵丹，布在自己的一块洞府上；每块地最多 1 处，每人同时最多 2 处。所有人都能看到。
- **触发**：他人一次移动**停在**这块地上，付完租金后，再交 100 灵石给地主，并被定身（下回合不能移动、原地结算）。禁制随即消耗。
- 地主本人停留、定身后的原地结算不会触发。洞府易主（灵丹换地、破产重整）时禁制消失。护道不挡禁制。
