数字在 phase 0 开始时（基线提交 35c3b01）重新跑过。之前这里贴的是更早一版代码的结果，先手胜率写的是 26.8%。`--json` 输出同样的报告，`npm run sweep` 可以对 `config.json` 里任意数值做多种子扫描。

（每局随机分配英雄座位、AI 性格随机；`--difficulty hard` 的结果相近：法修 40.6%，进神道 6.00 次/人。）

**对照 GDD §16 的目标：**

- **法修明显偏强（约 40%）。** 额外跑了 300 局统计修为来源：法修每局从「悬赏」拿到约 1.2 修为（其他英雄约 0.13）。大招「五雷正法」只要 3 灵丹，就能让修为第一名的洞府降级并 +1 修为，可用 2 次；被动「灵息」又带来更多灵丹，所以突破也更多（2.17 次/局，其他英雄约 1.55）。建议考虑：悬赏不对大招生效、每人限领 1 次，或调整大招费用。
- **几乎从不达到 10 修为（3.0%）。** 修为主要来自筑府（楼阁 / 仙府首建，人均约 3.5），任务（0.12）和斩妖（0.07）很少。平均 14.99 轮是因为几乎每局都打满 15 轮，而不是按节奏在 12–15 轮间结束。可以考虑把胜利线降到 8，或增加修为来源。扫描结果：`winCultivation` 取 8 时飞升结束约 27.5%，法修仍约 41%，先手仍约 29.5%（`npm run sweep -- --param winCultivation --values 8,9,10`）。
- **先手优势超出目标。** 种子 1–4 各 500 局，1 号位胜率 28.0–29.0%，比公平值 25% 高 3–4 个百分点，GDD §16 要求小于 3%。人均突破 1.70 次，在 1.5–2.5 范围内。
- **GDD §16 的两项观察指标。** 第 10 轮修为领先者最终获胜 65.8%。「无事可做」回合按严格口径统计：该回合玩家遇到的每个决策都是只有默认选项的掷骰 / 结束回合，结果只有 0.4%。如果把「只是掷骰并结束回合、没有做任何购买或出符」也算作无事可做，比例约 2.9%。2026-11-04 策划确认采用严格口径。
- 以上数字反映的是当前 AI 的打法（规则见 §13，阈值见 `src/ai/ai.ts`），不等于人类玩家的真实平衡。

## 2. GDD / 数据中的矛盾与歧义（已按下列方式实现）

1. **天魔停留与白泽驱散（§9.3 / §10，config `demon.stayRounds: 4`）。** 离开轮次为 `leaveRound = spawnRound + stayRounds`。第一只第 5 轮出现，本该在第 5–8 轮在场，第 8 轮开始时被白泽现世提前驱散，所以实际在场第 5–7 轮。第二只第 10 轮出现，在场第 10–13 轮。现世那一轮天魔不移动、不破坏洞府，直接被驱散，无人得修为。
2. **地火喷发「有主且 Lv≤1 的洞府降 1 级」（§3.4）。** Lv0 已经无法再降，所以只有 Lv1（草庐）的火域洞府会受影响。如果本意是 Lv≥1（和天魔一致），只需改 `engine.ts` 中 `eruption()` 的筛选条件。
3. **神通牌堆「不可重复」+「其余放回并洗牌」（§9.2 / §9.4）。** 没有说明牌堆是全场共用一套还是每人一套。如果全场共用 8 张，人均 2 次突破就会把牌抽光，所以按**每人一套**实现：从自己尚未拥有的神通里翻牌，不同玩家可以拥有同一个神通。
4. **「每回合」指单人回合还是整轮。** 聚灵「每回合首次收租」按整轮算（每轮 1 次），否则在别人的回合里收租每轮最多可触发 3 次。金身、缩地成寸「每 3 回合」按 3 轮冷却；护道「4 回合」按 4 轮算（第 8–11 轮）；不动明王「本回合与下回合」按该玩家自己的 2 个回合算。
5. **折扣符时机为「行动」（§11.1），但购地发生在行动阶段之前。** 只在行动阶段能用的话，它基本只能用于升级。因此掷骰前也允许使用（本回合购地 / 升级都打 7 折）。
6. **大招时机。** §6 把大招放在行动阶段，但御剑飞行（点数 ±3）和不动明王（免租）只有在移动前才有意义。实现为：体修在掷骰前或行动阶段都可用；剑修只能掷骰前用，只影响下一次移动（不覆盖双数再掷）；法修、丹师在行动阶段用。
7. **思过崖「面壁 1–3 回合」/ `cliffMaxTurns: 3`。** 停在思过崖（或因三连双数、犯戒受罚被送去）即开始面壁，护道期间免疫。之后每个回合开始计 1 次面壁：第 1、2 次可以付 100 灵石离开、用清心符离开，或掷骰（掷出双数就按这次点数移动，不再掷；没掷出双数则不移动，但仍有行动阶段）；第 3 次自动离开并正常行动。
8. **全场修为最低者翻 4 张（§9.2）。** 修为并列最低的人也算"最低者"。
9. **宗门供奉「向修为最高者支付」。** 自己并列最高时无事；有多个对手并列最高时，付给座位号最小的那位。
10. `heroes.json` 的 `color` 字段（gold/white/red/blue）与 p1–p4 的座位色一致，但英雄可以坐任意座位。UI 的归属条、旗子、头像框等一律用**座位色**；英雄色只用于占位图。
11. 很多规则数值只写在 GDD 正文或卡牌描述里，JSON 中没有对应字段：丹师 9 折、折扣 7 折、强购 1.5 倍、剑气 20、点金 200、神行 +1..3、身轻 ±1、御剑 ±3、天魔伤害 2/3、镇妖 ×2、斩妖 +2、悬赏 +1、护道 4 轮、灵脉馈赠 400、丹霞 4、灵泉 / 丹炉 / 白泽祠的灵丹数、金身 / 缩地冷却、丹心阈值等。这些已经迁入 `config.json` 的 `rules` 块（类型见 `src/core/types.ts` 的 `RulesConfig`），可以直接用 `npm run sweep` 调。`rules.chartDraw`（白泽图抽符张数）原来在引擎里写死成 1 张，没有读这个配置，现在已经接上。

## 3. 其他规则解读

**移动**
- 从神道外出到山门时，不在这座山门再次提供岔路选择。回合开始时站在山门上，可以选择拐入神道。
- 在神道上移动的方向会被记住：借道向外走、中途停在 X1/X2 的玩家，下回合继续向外；向内走的继续向内。
- 借道离开时"沿外环顺时针"按本次移动的方向执行（用了回首符就是逆时针）。可以从进来的那条神道原路出去。
- 宗门山门「经过 +200」：无论顺时针、逆时针（迷踪 / 回首符），还是遁地符走过都算；传送阵、指路、缩地等传送不算经过。
- 寒冰滑行只在沿外环走完一次移动后触发；传送、遁地符和误入幻阵的后退都不滑行。
- 瘴泽泥沼：本回合（含双数再掷）第一次进入土灵田时就记为已触发，即使当时剩余步数已经是 0。
- 迷踪：上回合结束时停在木灵田上的，本回合掷骰（及调整点数）**之后**选择方向，只对本回合第一次移动有效。
- 双数：完整回合（掷骰、移动、结算、行动阶段）之后再来一次。每回合升级 1 次、泥沼 1 次的限制覆盖整个回合（包括再掷）。第 3 次双数立即送往思过崖，不移动，回合结束。
- 剑气：移动中**经过**有其他玩家的格子时，从每名对手处各夺 20（落点和滑行不算）。
- 灵息：法修进入灵泉或丹炉时 +1 灵丹，经过和停留都算（停留时另外照常拿地块奖励）。
- 误入幻阵：沿本回合走过的路径后退 3 格（路径不够时继续沿外环或神道往回走），不触发经过效果，然后结算落点。
- 遁地符只能在外环上使用；缩地成寸的"当前灵域"按外环所在的一条边（含角格，共 8 格）计算：R0–R7 木、R8–R15 火、R16–R23 水、R24–R31 土。

**结算与经济**
- 定身符：目标下回合跳过掷骰，直接结算所站的格子（站在宗门山门会再拿 400；站在他人灵田要再付一次租；站在思过崖不会再次入狱）。
- 破产重整只由"付给其他玩家的钱"触发（租金、宗门供奉）；付给系统的损失（劫修拦路、心魔侵扰）不够就扣到 0。修为 −2 扣在永久修为上，灵脉之主加成随灵田归还自然消失。
- 灵丹换地的价格 = 1.5 ×（地价 + 已投入的升级费），保留建筑等级；原主可以用金光符抵挡（大招照样消耗）。
- 五雷正法在防御判定上视同五雷符：金光符、金身、铜皮铁骨、护道都能挡；也可以拿悬赏。金光符还可以抵挡地火喷发（§3.4），但不能挡天魔。
- 五雷符 / 五雷正法的目标列表里不出现受护道保护的玩家和体修的楼阁 / 仙府。
- 突破时只要持有祠印就会消耗，即使天魔的 +1 把它抵消了。
- 天魔出现在 20 块灵田中随机的一块（有主无主都可能），出现时不破坏洞府，只有移动后落在 Lv≥1 的洞府上才降级。
- 白泽现世时，按修为升序、再按灵石少者优先、再按座位号依次挑选天赐。「指路」在别人的回合中立即结算（可以直接去灵台突破）。「天降祥瑞」由玩家依次选 2 块洞府，Lv3/Lv4 首建修为照给。
- 灵兽引路：下一次移动不掷骰，直接选 1–6 点（不算双数）。

**卡牌、任务与胜负**
- 机缘牌：已经持有 2 张任务时又抽到任务，就弃掉重抽。保底计数：只有负面事件才计入连败；正面事件和任务都会清零。保底触发时，从抽牌堆取第一张正面事件（没有就从弃牌堆取）。
- 任务在**每个回合结束时对所有玩家**检查。累计类任务（收租 500、突破、伤害天魔）从接任务那一刻开始计数。
- 修为变化后**立即**判胜（包括灵脉之主变动），不必等到回合结束。突破机会按历史最高总修为（含灵脉加成）跨过 2/4/6/8 来累积。
- 第 15 轮结束时的平局，依次比较修为、总资产（灵石 + 灵田与升级投入 + 灵丹 × 50）、座位号。

## 4. 简化 / 占位

- **交易**：未实现（按钮禁用，T 键提示"暂未开放"）。按 GDD 规定，AI 回合本来也跳过交易。
- **坊市**：只能盲抽购买牌堆顶的符箓，不能挑选。
- **手牌上限**：超过 5 张时，新抽到的牌自动作废，不让玩家选择弃哪张。
- **神识「随时查看对手手牌」**：持有神识的人类玩家，可以在左栏玩家卡底部看到对手手牌的名字；AI 不利用这一信息。
- **AI**：普通难度完全按 §13 的表格。简单难度买地 50% 随机，不用任何攻伐符，挑神通 / 天赐带随机性。困难难度在岔路和买地时做一步前瞻（用 2–12 点的分布估算落点收益 / 租金风险），挑神通 / 天赐时考虑局势；其他阈值同普通。三种性格只调整阈值和偏好。
- **UI**：没有设置界面和音频；标题界面并入设置界面。弹窗是通用样式，只有购地带地块预览，神通 / 天赐用卡牌样式。"出符"菜单里同时列出大招和缩地成寸。
- **存档**：`GameState` 是纯 JSON，但 generator 的执行位置不能序列化。存档请用 `Game.replay(setup, history)`（种子 + 回答历史）重放（有测试覆盖）。
- **字体**：使用 Phaser Text 加系统字体回退，正式版需要换成位图像素字体。
