# 棋盘设计：通用路网与 77 格大地图

> 这两节原是 `game/NOTES.md` 的 §10、§11，棋盘约束仍然有效，改地图前请先读。其中对 41 格旧图、天魔等 v0.7 以前系统的说法是当时的记录，现行规则见 GDD。

## 10. 2026-11-05 棋盘改为通用路网（为大地图做准备）

`data/board.json` 不再写死「外环 + 4 条神道 + 灵台」，改成一张有向路网：`nodes` 里每格用 `next` 写前进方向的后继格，多于一个就是岔路，`next[0]` 是主线。反向移动沿 `next` 的反向边（`prev`）走，`prev` 按 `nodes` 的书写顺序生成。现有 41 格地图的每条规则保持原样，用 golden（8 组 500 局模拟 + 8 份战报）和 3000 局随机/AI 混合回答的事件哈希比对过，逐字一致。

**规则在路网上的写法**
- **外环**：原来按「在外环上」判断的规则，改看格子上的 `outer` 标签。包括迷踪、逆行符、遁地符、缩地成寸、镇山、乾坤挪移，以及地块面板的「外环」字样。
- **神道是双向通道**：神道格把内外两个邻格都写进 `next`。走路时不能掉头回到刚来的格子，所以拐进神道就一直向内，借道出来就一直向外，出神道到山门时也不会再问岔路。原来的 `roadDir`（'in' / 'out'）换成 `PlayerState.cameFrom`（上一步来自哪一格）。站在双向格上又没有 `cameFrom` 时（传送、误入幻阵之后），按 `next[0]` 走，也就是向内。
- **岔路**：选项是可走的后继格，按 `next`（反向时按 `prev`）的顺序排列，默认第一个。选项文字沿用原来的写法：进入另一条神道显示「拐入某神道」，外环格显示「继续外环」，其余显示「前往【格名】」。只有选了神道格才计入「进入神道次数」。
- **灵台**：仍然是 id 为 `ALTAR` 的单个节点。出发和借道时的选项就是灵台的 `next`（四条神道的第 2 格），选项文字里的山门由「沿神道走到第一个非双向格」求出。
- **镇山、天魔、遁地、AI 看前方租金**：都是「沿主线前进」，即每步取 `next[0]`。
- **乾坤挪移的距离**：只经过外环格、顺逆两个方向都算，取最短步数。
- **缩地成寸**：可以去「当前格 `region` 相同」的任意格。外环的角格和山门也写了 `region`，按所在的边归属（R0–R7 木、R8–R15 火、R16–R23 水、R24–R31 土），和原来按边划分的结果一样。站的格子没有 `region` 时不提供缩地。
- **寒冰滑行**：沿这一步的方向再走一格。如果正好停在岔路口，滑向主线（第一个出口）。现有地图上的水域灵田都不是岔路口。
- **误入幻阵**：先沿刚走过的路退回；路走完了还要退，就沿主线反方向退。双向格上一律取 `prev[0]`，在现有地图上就是向外（灵台退到南神道）。

**AI**
- 普通难度的岔路规则「想突破，或前方 6 格有重租 → 拐入神道」，改成「→ 选离灵台最近的出口」（沿 `next` 到灵台的最少步数），否则走主线。
- 困难难度的一步前瞻对每个非主线出口各预测一次，取比主线落点分数高的最好一个。原来就有的两个小偏差保留不动：反向移动时前瞻仍按正向预测；预测器在镇山拦截时先停下、不计经过山门。

**存档**
- 岔路、出灵台、借道这三种决定的回答 id 从 `ring` / `road` / `S` 等改成了格子 id（如 `S1`、`R5`、`E2`），旧记录无法再复现。对局记录格式版本因此从 1 升到 2，旧的自动存档和下载的记录会直接提示「不支持的记录版本 1」。

**换大地图时要提供的数据**
- 必需：每格的 `id`、`type`、`pos`、`next`；一个 `type: "start"`、一个 `type: "cliff"`；一个 id 为 `ALTAR`、`type: "altar"` 的灵台（`rect` 写它占的格子）。
- 灵田要有 `region`、`name`、`price`。希望缩地成寸可用的非灵田格也写 `region`。
- 神道式的双向通道把两头都写进 `next`，并标 `road`（在 `roads` 里给名字）。灵台的 `next` 就是借道和出发时的出口。
- 想让迷踪、逆行符、遁地符、缩地成寸、镇山、乾坤挪移生效的格子标 `outer: true`。
- 遁地符沿主线找下一座 `gate`，主线上至少要有一座山门。
- `street`（地段连锁）：§11 的新地图已经给每块灵田填了街道，但现在没有任何规则读它。

## 11. 2026-11-05 大地图：77 格、内外两环、四个灵域（`config.json` 版本 0.6）

试玩反馈：地图太小、路线单调。`data/board.json` 换成 77 格的大地图，并按新地图重新调了数值。§1–§10 里的 `R0–R31`、`S1/S2`、「外环」都是指旧的 41 格环形图，旧图保留在 `game/tests/fixtures/ring-board.json`。规则测试继续用它（`helpers.ts` 的 `ringGame()` / `ringData()`），所以换地图不会改变那些测试的含义。

- 77 格：44 块灵田、8 座山门、8 座历练碑、4 灵泉、4 坊市、4 丹炉，宗门山门、思过崖、传送阵、白泽祠各 1，灵台 1。每个灵域 11 块灵田，分 3 条街道（巷 3 块、里 3 块、街 5 块），共 12 条街道，名字在 `streets`。
- 主线是 40 格外环（一圈 40 步，约 5.7 个回合）。每个灵域有 3 个岔路：外山门 X2（外环 / 入梯历练碑 X10）、内山门 X14（长街 / 神道）、长街尽头 X16（出梯历练碑 X17 回外环 / 继续下一条长街）。
- **为什么这样排**：四条长街连成内环，是所有人去灵台的必经之路，长街的地价也最高。这样玩家经常在内环相遇、互相付租。外环两条短街便宜，适合开局抢地。每个灵域的丹炉都在主线上（X1），灵泉在神道上，所以去灵台突破的路线和攒灵丹的路线是同一条。
- 题材名全部是通用修仙地名（竹溪村、离火殿、镜湖居……），不涉及具体作品。

**规则在新地图上的处理**
- **「外环」= 路网格**：除神道（灵泉）和灵台以外的所有格都标 `outer: true`。迷踪、逆行符、遁地符、缩地成寸、镇山、乾坤挪移因此在内环长街上也能用。只标 40 格外环会让内环成为这些规则的死角，玩家会觉得「同样是街，为什么这里不行」。说明文字从「外环」改成「路网」（`heroes.json` 乾坤挪移、`blessings.json` 缩地成寸、GDD §3 / §9.4 / §12）。
- **岔路选项文字**：原来外环格显示「继续外环」，现在一律显示「前往【格名】」（`engine.ts` 的 `askFork`）。内环格也是 `outer`，「继续外环」会写错。进神道仍显示「拐入某神道」。
- **神道只有 1 格**（灵泉），双向。灵台出发和借道的四个出口就是四座灵泉。
- **一域独占**还是「拥有该灵域全部灵田」，现在要 11 块，基本不会出现。见下面的待确认问题。
- **UI 没改**：地块提示 `ui/TileInfo.ts` 对所有 `outer` 格显示「外环 X」，内环格也会显示「外环」。这个文件归画面那边，留给他们改。

**地图检查**（`src/sim/boardcheck.ts`，`npm run board`，`tests/board.test.ts`）
- 结构：id 唯一、`next` 指向存在的格、恰好 1 个起点 / 1 个思过崖 / 1 个灵台（带 `rect`）。
- 几何：格子在网格内、不重叠（灵台的 3×3 也算）。每条边横平竖直、中间不穿过别的格子，连灵台的边要贴着灵台。
- 走法：按（格子，上一格）状态从起点出发搜索。没有死路、每格都能到达、任何状态都能回到起点；反向移动（沿 `prev`）也不会卡住；每个路网格沿主线都能找到山门（遁地符）。
- 内容：灵田有灵域、名字（不重名）、价格和同灵域的街道。每个灵域至少 2 个岔路，有灵泉、丹炉、历练碑、坊市，3 条 3–5 块灵田的街道。
- 测试里还故意弄坏地图（未知后继、切断一条岔路、第二个思过崖、重叠 + 缺街道、去掉坊市），确认检查能报出来。这些用例不写死格子 id，换地图也能跑。

**困难难度不达标的部分**
- **座位**：困难 AI 会绕开高租地块（付租回合只有约 5%，普通约 14%），后手补偿的灵石几乎不会被租金吃掉，变成纯优势。补偿越小困难越平、普通越偏先手，两者方向相反（2000 局，各座位胜率的最低–最高）：

  | 起始灵石 + 后手补偿 | 普通 s1 / s3 | 困难 s1 / s3 |
  |---|---|---|
  | 1500 + 300/600/900（采用） | 23.9–25.7 / 24.2–26.1 | 20.6–29.6 / 22.3–27.7 |
  | 1650 + 250/500/750 | 23.9–27.3 / 24.0–27.3 | 21.4–27.7 / 23.2–26.6 |
  | 1800 + 200/400/600 | 20.8–30.6 / 22.3–28.2 | 23.7–25.7 / 24.6–25.5 |

  只降补偿（1500 + 100/200/300）时困难座位是 23.9–26.9%，但修为结束跌到 62.5%：总灵石少了，筑府慢。采用了对普通难度（默认难度）最好的一档。41 格图的困难难度也有超标（§1）。
- **剑修 28–30%**：困难 AI 用剑遁找人斗法更准。范围再收到 6 格时，困难剑修 27.0 / 28.3%，普通英雄 23.1–26.6%，但普通互动降到 41.7 / 42.0%。为了保住互动留在 8。想优先困难平衡，就把 `rules.swordDashRange` 改成 6。

**主线走内环的对照**：把每个岔路的 `next` 顺序反过来，主线变成走长街（一圈 56 步，约 8 回合，接近设计稿「一圈 8–10 回合」）。最终数值下种子 1 普通 2000 局：英雄 24.1 / 26.3 / 25.9 / 23.7%，座位 25.3 / 22.8 / 24.3 / 27.7%，10.86 轮，72.8% 修为结束，互动 43.0%，和现在差不多。没采用的原因：主线不经过外环 X3–X6（便宜的巷和坊市），普通 AI 几乎不去坊市。只改 `next` 顺序就能切换，留给策划决定。

**第三层（百宝阁、小游戏、医馆）准备改的格子**

现在只用已有地块类型。下面这些格子是给新地块留的位置，改 `type` 即可，路网不用动：
- **小游戏**：每个灵域两座历练碑中改一座，建议出梯 X17（W17 / F17 / S17 / E17）。X16 的主线出口就是 X17，走完长街默认都会经过，人流最大；入梯 X10 保留历练碑。
- **百宝阁**：坊市 X6。设计稿写「坊市或百宝阁」，建议地价高的火、水两域（F6、S6）改百宝阁，木、土（W6、E6）保留坊市。
- **医馆**：内山门 X14 之一，建议 E14。岔路由 `next` 决定，不看类型，改了照样能拐进神道。遁地符找的是主线上的外山门 X2，不受影响。「一回合经过两座山门」的任务会少一座可数的山门。

**待策划确认**
1. 主线一圈 40 步（约 5.7 回合），设计稿想要 8–10 回合一圈。可以切到内环主线（56 步，见上），或者在每条边再加格子（网格要扩到 13×13）。
2. 设计稿把每个灵域放在一个角上，这张图是每个灵域占一条边，四个角放特殊格。
3. 剑遁加了 8 格范围（`rules.swordDashRange`），是新规则。
4. 困难难度的座位差和剑修，见上。
5. 一域独占要 11 块，基本不会出现。建议改成「一街独占」（地段连锁，`street` 字段已经填好），需要改 `rules.ts` 的 `rentFor` 并重新跑平衡。
6. 内环格在地块提示上显示「外环」（`ui/TileInfo.ts`），需要画面那边改文字。
